# ADR 0031 — Generated Dart API client is committed to the repository

- **Status:** Accepted
- **Date:** 2026-07-22

## Context

Contract §146 asks whether the generated Dart client is committed or generated on demand. Mobile CI and fresh clones need to compile without a running backend.

## Decision

Committed, at `apps/mobile/lib/core/network/generated/` (per frontend docs). Regenerated by `scripts/generate-api-client.sh` from `packages/api-contracts/openapi/antrein-v1.json`; never hand-edited. The contract-check CI workflow regenerates and fails on diff, keeping the committed client honest.

## Consequences

- Contract changes show up as reviewable Dart diffs in PRs.
- Flutter builds are self-contained; generator toolchain needed only when the contract changes.
- Prisma client stays gitignored (backend-internal, regenerated per install) — the asymmetry is deliberate: the Dart client crosses the app boundary.
